# The Chair Leg Feud

A one-line roast of the robot vacuum: it maps the whole apartment down to the centimeter, then spends its entire shift ramming a single chair leg like it owed it money.

`main.ts` writes the line to `/output/entry.txt`. The line also lives in `entry.txt` beside the script; the program reads it from there when present and falls back to an embedded copy otherwise.
